# To-Do List App - Week 1

## Overview
This is a simple Flutter application developed as part of Week 1 for the Flutter development internship. The main focus of this week is understanding Flutter's basic structure, building responsive user interfaces, implementing navigation between screens, and adding form validation.

## Features

*   **Login Screen:** A responsive dark-themed UI with email and password fields.
*   **Sign Up Screen:** Register a new account with name, email, and password (with strict validation rules).
*   **Validation:** Email format checks, password strength rules (8+ chars, uppercase, lowercase, number, special char), and name alphabets-only filter.
*   **Navigation:** Successful login navigates to the Home Screen. Sign-up redirects back to Login.
*   **Demo Account:** A built-in demo account is available for quick testing.
*   **Structured UI:** Built with Column, Row, Container, and a centralized dark mode color theme.

## Getting Started

1.  Make sure you have Flutter installed and set up on your machine.
2.  Clone the repository.
3.  Open the project in Android Studio or VS Code.
4.  Run `flutter pub get` to fetch dependencies.
5.  Connect a device or start an emulator/simulator.
6.  Run `flutter run` to launch the application.
