# To-Do List App - Week 1

## Overview
This is a simple Flutter application developed as part of Week 1 for the Flutter development internship. The main focus of this week is understanding Flutter's basic structure, building responsive user interfaces, implementing navigation between screens, and adding form validation.

## Features

*   **Login Screen:** A basic responsive UI containing email and password input fields.
*   **Validation:** Email formatting and password emptiness are properly validated before login.
*   **Navigation:** Successful login navigates the user to a Home Screen.
*   **Structured UI:** Built utilizing standard Flutter layout widgets such as Column, Row, and Container.

## Getting Started

1.  Make sure you have Flutter installed and set up on your machine.
2.  Clone the repository.
3.  Open the project in Android Studio or VS Code.
4.  Run lutter pub get to fetch dependencies.
5.  Connect a device or start an emulator/simulator.
6.  Run lutter run to launch the application.

## Learning Objectives Addressed
*   Understand Flutter's basic structure.
*   Build simple and responsive user interfaces.
*   Learn navigation between screens.
